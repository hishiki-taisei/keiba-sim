# keiba-sim

過去のレースデータから各馬の能力を推定し、簡易的にモデル化したコースで馬を
実際に何千回も走らせて、勝率・複勝率を予想するシミュレーターです。
目標は2026年の菊花賞（京都 芝3000m）の予想です。

## いまできること

- 京都 芝3000m（外回り）のコースモデル：コーナー、直線、3コーナーの坂（2回通過）
- レースシミュレーション（`sim/race.py`）：各馬がスピード・スタミナ・瞬発力・脚質・馬番を持ち、
  ペース、スタミナ消費、坂、コーナーの外回りロス、前が詰まる・後ろにつけて脚をためる、を再現
- モンテカルロで勝率・複勝率・平均着順を計算
- ブラウザでレースを再生するアプリ（`web/`）

デモは架空の馬にランダムな能力値を与えたもので、実際の予想ではありません。

## 使い方

```bash
pip install -r requirements.txt
python3 scripts/demo.py          # web/data/demo.json を作る
python3 -m unittest              # テスト
cd web && python3 -m http.server # http://localhost:8000 で表示
```

`web/` はそのまま Cloudflare Pages に置ける静的サイトです。
別のレースは `web/data/<名前>.json` に置き、`?race=<名前>` で表示します。

## データ収集（`scraper/`）

netkeiba のレース結果ページ（db.netkeiba.com）から、JRA全レースの結果を SQLite に集めます。
アクセスは1.2秒＋ゆらぎの間隔を空け、403/429/5xx のときは長めに待ちます。取得したページは
`data/raw/` に gzip で保存するので、同じページを二度取りに行きません。

```bash
scripts/collect.sh                    # 2015年1月〜今日まで。止めても再実行で続きから
python3 -m scraper status             # 進み具合
python3 -m scraper reparse            # パーサーを直したあと、保存済みページから作り直す
```

| テーブル | 中身 |
|---|---|
| `races` | 日付、競馬場、芝/ダ/障、距離、回り、天候、馬場、クラス、ラップ、コーナー通過順 |
| `results` | 着順、枠・馬番、馬・騎手・調教師ID、性齢、斤量、タイム、通過順、上がり3F、単勝オッズ、人気、馬体重 |
| `payouts` | 単勝〜三連単の払戻金と人気 |
| `horses` | 父・母・母父・父父（血統ページから） |

DB（`data/keiba.sqlite`）は大きいのでリポジトリには入れていません。

## 能力値の推定と検証（`model/`）

1. **スピード指数**（`model/rating.py`）：各レースで馬の平均速度をそのレースの中央値と比べ（%）、
   対戦相手を通じて全馬を1つの物差しに乗せます。馬ごとに「能力」と「距離が倍になったときの伸び縮み（距離適性）」を推定し、
   最近のレースほど重く扱います。毎月はじめに、その時点までのデータだけで推定し直します（未来のデータは使いません）。
2. **勝率モデル**（`model/logit.py`）：スピード指数、距離適性、近走の着順・人気・位置取り・上がり、賞金、休み明け、
   距離変更、斤量、馬番、騎手の成績から、レースごとのソフトマックスで勝率を出します。
3. **シミュレーター**（`model/to_sim.py`）：勝率モデルの点数を最高速度とスタミナに、近走の位置取りを脚質に、
   上がりを瞬発力に変換して、レースを走らせます。係数は2023年の2400m以上で決めています。

期間の分け方：学習 2018〜2022年、調整 2023年、テスト 2024年1月〜。

```bash
python3 scripts/backtest.py --rebuild   # 特徴量を作り、勝率モデルを評価（data/backtest.json）
python3 scripts/sim_backtest.py         # シミュレーターを調整・評価（data/sim_backtest.json）
```

テスト期間（2024年〜）の結果。「本命」はいちばん勝率が高いと出た馬です。

| 対象 | 予想 | 本命の勝率 | 本命が3着以内 | 対数損失（低いほど良い） |
|---|---|---|---|---|
| 芝 全4,642レース | 勝率モデル | 27.4% | 58.1% | 2.120 |
| | 単勝オッズ（市場） | 33.6% | 65.5% | 1.909 |
| 芝2400m以上 349レース | シミュレーター | 28.4% | 64.5% | 2.026 |
| | 勝率モデル | 30.9% | 65.9% | 1.939 |
| | 単勝オッズ（市場） | 39.5% | 70.2% | 1.767 |

まだ市場のオッズには届いておらず、オッズと組み合わせても上積みはありません。本命の単勝を買い続けた場合の回収率は
芝全体で88%、シミュレーターの本命（2400m以上）で67%です。

## 計画

1. データ収集：過去10年ほどのJRAのレース結果・馬・血統・騎手・オッズ・タイム
2. 能力値の推定：過去の走りから各馬のスピード・スタミナ・瞬発力・脚質を推定
3. 検証：年で学習用とテスト用に分けて実際の着順と比べ、馬券の買い方ごとの回収率も確認
4. 公開：Cloudflare Pages。菊花賞の枠順確定後に予想を更新
