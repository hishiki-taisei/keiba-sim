# レース再現（theater/）

各馬の特徴量から、コース上を馬が走る様子をブラウザで再現する部品です。
「もう一回」を押すたびに別のレースになり、1000回まとめて走らせた勝率は
予想モデルの勝率とほぼ同じになるように合わせてあります。他のコード（`sim/`、`model/`、`portal/` など）には依存していません。

```bash
cd theater && python3 -m http.server   # http://localhost:8000/?race=kikka2026
```

## サイトへの組み込み

```html
<script type="module" src="theater/player.js"></script>
<race-theater src="theater/data/kikka2026.json"></race-theater>
```

`player.js` と同じ場所に `engine.js`・`course.js`・`tally-worker.js` を置きます。スタイルは `.rt` の下だけに効き、
色は `.rt` の CSS 変数（`--ink` `--paper` `--accent` など）で上書きできます。ライト・ダークの両方に対応しています。
JSON を読み込まずに `element.field = {...}` で直接渡すこともできます。1ファイルにまとめたいときは
`python3 theater/tools/bundle.py out.html kikka2026 arima2025` を使います。

## 画面でできること

- コース俯瞰のアニメーション（馬群を追う／コース全体、×1〜×16）、隊列、実況の一行、結果表（着差・通過順・上がり）
- ペース（おまかせ・スロー・平均・ハイ）と馬場（良〜不良）を変えて走らせる
- 1000回走らせた勝率・3着内率・平均着順・4角の位置を、モデルの勝率と並べて表示

## レースの作り方

```bash
# これからのレース：予想CSV（馬・勝率(モデル)、あれば騎手・馬番）から
python3 theater/tools/build_field.py --predictions preds.csv --date 2026-10-25 \
    --venue 京都 --surface 芝 --distance 3000 --outer --title "菊花賞 2026" --out theater/data/kikka2026.field.json
# DBにある過去のレース：枠順と実際の着順つき。確率は単勝オッズ（--predictions を付ければモデル）
python3 theater/tools/build_field.py --race-id 202506050811 --out theater/data/arima2025.field.json

# 勝率をモデルに、勝ちタイムを過去の同コースに合わせる
node theater/tools/calibrate.mjs theater/data/kikka2026.field.json theater/data/kikka2026.json
```

JRA の全10場（芝・ダート、内回り・外回り、新潟の直線1000m）に対応しています。

## 仕組み

**各馬の特徴量**（`build_field.py`、レース日より前の近8走から。新しい走りほど重く扱う）

| 項目 | 中身 |
|---|---|
| 脚質 `style` | 1角の位置（0＝先頭、1＝最後方）の平均 |
| まくり `move` | 1角から4角までに上げた順位 |
| 上がり `kick` | 上がり3Fがそのレースの中央値より何秒速いか（同じ芝・ダートの走りだけ） |
| 長距離 `stamina` | 2200m以上での着順の良さと、それより短い距離との差 |
| 道悪 `going` | 稍重〜不良での着順の良さと、良馬場との差 |
| ムラ `form_sd` | 着順のばらつき。大きい馬ほど日によって走りが変わる |
| 能力 `ability` | `calibrate.mjs` が決める。勝率がモデルと合うまで調整 |

**レース**（`engine.js`、0.25秒刻み）：同じコース・距離の過去のラップ（重賞はなるべく重賞だけ）から、前半・中盤・
残り1000〜600m・最後の600m のペースを作ります。各馬は脚質に合った位置を取りに行き、スタミナを速度の3乗と坂で消費し、
前の馬の後ろにいると少し節約し、コーナーで外を回ると距離を損し、前が詰まると外に出します。残り800m前後から
まくる馬は押し上げ、最後は上がりの速さとスタミナの残りで伸びが決まります。大きく離された馬は直線で追うのをやめます。

**合わせ込み**（`calibrate.mjs`）：枠順が決まっていなければ毎回抽選し、4000回×16回走らせて、勝率がモデルとずれた分だけ
能力を動かします。同時に、勝ちタイムの中央値が過去の同じコースの中央値になるように全体の速さを合わせます。

| レース | 勝率のずれ（平均／最大） | 勝ちタイム（中央値） |
|---|---|---|
| 菊花賞2026（登録21頭） | 0.2／0.5 ポイント | 184.3秒（過去の同コース 184.1秒） |
| 有馬記念2025（中山芝2500m） | 0.2／0.5 ポイント | 152.9秒（過去の同コース 152.8秒） |
| フェブラリーS2026（東京ダ1600m・左回り） | 0.4／1.3 ポイント | 95.5秒（過去の同コース 95.5秒） |

**簡略化していること**：コースは2本の直線と半円2つの形で、長さ・直線の長さ・坂の位置と高さだけを実際に合わせています。
ポケット（引き込み線）からのスタートも周回コース上から出ます。騎手の判断や斤量、馬体重は入っていません（勝率は
モデルに合わせてあるので、そちらに入っている分は反映されます）。
