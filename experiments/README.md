# モデルの記録

試したモデルを1行ずつ記録しています（`python3 scripts/experiment.py` が自動で更新）。
学習 2018〜2022年、調整 2023年、テスト 2024年1月〜。対数損失は低いほど良く、
「本命」はモデルがいちばん勝率が高いと出した馬です。菊花賞型は「3歳・芝2400m以上・9〜11月」。
勾配ブースティング（gbdt）は調整期間で学習の止めどころを決めているので、比べるときはテストの列を見てください。

**オッズ＋モデル**：モデルの勝率と単勝オッズの勝率を、調整期間で決めた重みで混ぜたもの（Benter の2段階法）。「オッズ単独との差」がマイナスなら、モデルがオッズの知らない情報を持っているということです。±は誤差の目安（標準誤差）で、差がこの2倍より大きければ偶然とは考えにくい差です。**期待値買い**：混ぜた勝率×オッズが1.2以上の馬（100倍超を除く）の単勝を買った回収率。確定オッズで計算しているので実際より甘めです。
